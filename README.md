# 项目说明 (Project Overview)

本项目包含主算法、对比实验、消融实验以及相关数据集。以下是各目录及实验环境的详细说明：

## 目录结构说明

*   **`data/` (数据文件夹)**
    包含主算法所需的数据。数据均为**已处理好的特征动态增加数据流**（Processed dynamic feature stream）。

*   **`comparison/` (对比实验文件夹)**
    包含所有对比算法的代码，以及主对比实验的运行程序。（注：建议将代码库中的 `comparsion` 文件夹重命名为 `comparison` 以防拼写混淆）

*   **`ice/` (消融实验文件夹)**
    包含消融实验的相关代码，具体为三个算法变体（Variants）的代码实现。

## 实验环境

*   **Python 版本**: Python 3.7
